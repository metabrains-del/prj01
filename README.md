# AI Bot — Intelligent Assistant Landing Page

A modern, responsive landing page for an AI-powered chatbot product. Built with pure HTML and CSS, no frameworks required.

## Overview

This project is a fully designed marketing/landing page for an AI Bot service. It showcases the product's features, pricing plans, user testimonials, and a FAQ section — everything a potential user needs to understand and sign up for the service.

## About the AI Bot

The AI Bot is a smart conversational assistant designed to help users automate tasks, get instant answers, and boost productivity. Key highlights:

- **Natural Language Understanding** — Processes and responds to user queries in plain English with high accuracy.
- **24/7 Availability** — Always on, no downtime, ready to assist at any hour.
- **Multi-domain Knowledge** — Handles questions across a wide range of topics including tech, business, education, and more.
- **Contextual Conversations** — Maintains context across a conversation for more coherent, relevant responses.
- **Fast Response Times** — Optimized for low-latency replies to keep interactions smooth and natural.
- **Scalable Plans** — Tiered pricing (Free, Pro, Enterprise) to fit individuals, teams, and large organizations.

## Features

- Responsive hero section with a full-screen background image
- Animated feature cards with scroll-triggered visibility
- Step-by-step "How It Works" section
- Testimonials grid with user avatars and quotes
- Pricing cards with a highlighted "Popular" plan
- Accordion-style FAQ section
- Call-to-action section with live stats and a scrolling logo banner
- Full footer with newsletter signup, social links, and contact info

## Tech Stack

- HTML5
- CSS3 (custom properties, flexbox, grid, animations)
- Google Fonts (Inter, JetBrains Mono)
- Font Awesome icons
